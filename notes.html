Creating & Organizing Your Notes

To add your notes:

  1. Create a new HTML file in the notes/ folder (e.g., note2.html).
  2. Add your notes using headings, paragraphs, lists, equations, or images as needed.
  3. Update this page to include a link to the new note file in the list above.

Organization Tips

Keeping your notes organized will help you find information quickly and reflect on what you’ve learned. Consider these ideas:

  • By Course or Subject: Group notes by course number or subject area (e.g., BME 501: Tissue Engineering, MATH 601: Real Analysis).
  • By Semester: Create subpages for each term (e.g., spring2026.html) that link to individual lecture notes.
  • Color Codes: Use subtle text highlights or headings to indicate difficulty or importance of topics.
  • Summary Sections: Add a brief summary at the top or bottom of each note page to capture key points or outstanding questions.
